# 🚀 ResumeIQ AI

ResumeIQ AI is an AI-powered resume analyzer that evaluates resumes using Large Language Models, providing ATS-friendly feedback and improvement suggestions.

## ✨ Features

- 📄 Upload resume images
- 🤖 AI-powered resume analysis
- 📊 Resume score out of 100
- 💡 Strengths and weaknesses
- 🎯 ATS improvement suggestions
- 📈 Resume analytics dashboard
- 📧 Email analysis report
- 🔐 User authentication

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- CSS
- Chart.js

### Backend
- Node.js
- Express.js
- Multer
- Groq AI
- Supabase
- Resend
